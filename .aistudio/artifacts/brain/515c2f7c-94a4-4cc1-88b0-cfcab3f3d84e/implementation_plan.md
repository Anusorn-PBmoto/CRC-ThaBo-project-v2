# ระบบจัดการลูกค้า สมาชิก และเกรดราคาพิเศษ (Customer Directory & Tier Pricing System)

แผนพัฒนาระบบสมาชิกและจัดเกรดลูกค้า (เกรด A, B, C, D และลูกค้าทั่วไป) พร้อมระบบคำนวณส่วนลดตามกลุ่มลูกค้า และการตั้งราคาเฉพาะสินค้าแยกตามเกรดสำหรับร้านอะไหล่และยางมอเตอร์ไซค์ CRC THABO

> [!IMPORTANT] การตัดสินใจที่ได้รับการยืนยันจากผู้ใช้งาน (User Review & Confirmed Decisions)
> - **การจัดเกรดลูกค้า (Customer Grading)**: แบ่งเป็น 5 ระดับ ได้แก่ **เกรด A, เกรด B, เกรด C, เกรด D และลูกค้าทั่วไป** โดยแต่ละเกรดมีเปอร์เซ็นต์ส่วนลดมาตรฐานที่สามารถปรับเปลี่ยนได้ (เช่น เกรด A 15%, เกรด B 10%, เกรด C 5%, เกรด D 2%, ทั่วไป 0%)
> - **ระบบการคิดราคา (Hybrid Tier Pricing)**: รองรับการกำหนดราคาเฉพาะของแต่ละสินค้าตามแต่ละเกรดได้โดยตรง หากสินค้านั้นไม่ได้ตั้งราคาเฉพาะไว้ ระบบจะคำนวณส่วนลดเป็นเปอร์เซ็นต์อัตโนมัติตามเกรดของลูกค้าจากราคาขายปลีก (ปัดเศษขึ้นเต็มจำนวนบาท)
> - **ข้อมูลลูกค้าที่จัดเก็บ (Customer Data Fields)**: ชื่อ-นามสกุล, เบอร์โทรศัพท์, เกรดสมาชิก, ทะเบียนรถ/รุ่นมอเตอร์ไซค์, ที่อยู่/หมายเหตุ, ยอดซื้อสะสมรวม (Total Spend), และจำนวนครั้งที่ซื้อ

---

## 1. ภาพรวมและแนวคิดหลัก (Overview & Core Concept)

- **ความสามารถของระบบ (What It Does)**:
  1. **สมุดรายชื่อลูกค้าและสมาชิก (Customer Directory)**: ค้นหา บันทึก แก้ไข และดูประวัติยอดซื้อสะสมของลูกค้าแต่ละรายได้อย่างสะดวกรวดเร็ว
  2. **ระบบตั้งค่าเกรดและส่วนลด (Tier Settings)**: กำหนดเปอร์เซ็นต์ส่วนลดมาตรฐานของแต่ละเกรด (A, B, C, D, ทั่วไป) ได้อย่างอิสระ
  3. **การตั้งราคาพิเศษรายสินค้า (Custom Grade Pricing)**: ในหน้าแก้ไขสินค้า สามารถระบุราคาเฉพาะสำหรับเกรด A, B, C, D แยกต่างหากได้
  4. **เชื่อมโยงหน้าขายอัตโนมัติ (POS Auto-Discount Integration)**: ทั้งในหน้าโหมดพนักงาน (Staff POS) และหน้าซื้อ/ขายหลัก เมื่อเลือกหรือค้นหาชื่อลูกค้า ระบบจะดึงเกรดมาปรับราคาในบิลให้อัตโนมัติ พร้อมแสดงส่วนลดชัดเจน และสะสมยอดซื้อให้อัตโนมัติเมื่อทำรายการเสร็จ
- **กลุ่มผู้ใช้งาน (Target Persona)**: เจ้าของร้าน, แคชเชียร์ และพนักงานขายหน้าร้าน ที่ต้องการอำนวยความสะดวกในการให้ราคาส่ง/ราคาช่างแก่ช่างประจำและอู่ซ่อมรถ
- **คุณค่าหลัก (Key Value)**: เพิ่มความรวดเร็วและแม่นยำในการคิดราคาช่างและลูกค้าประจำ ลดความผิดพลาดของพนักงาน ไม่ต้องคอยจำราคาหรือกดเครื่องคิดเลขคำนวณส่วนลดเอง

## 2. ประสบการณ์ใช้งานและการออกแบบส่วนต่อประสาน (User Experience & Visual Design)

### ขั้นตอนการใช้งานหลัก (Key User Flows)

1. **การค้นหาและเลือกลูกค้าในหน้าขาย (Staff POS & Buy/Sell)**:
   - ที่แถบข้อมูลลูกค้า จะมีปุ่มเลือก/ค้นหาลูกค้า (`ค้นหาชื่อ, เบอร์โทร, ทะเบียนรถ`) พร้อมปุ่มด่วน "+ เพิ่มลูกค้าใหม่"
   - เมื่อเลือกลูกค้า ระบบจะแสดง Badge เกรด (เช่น `เกรด A [ส่วนลด 15%]` หรือ `ช่างสมเกียรติ (เกรด A)`)
   - ราคาสินค้าในตะกร้าและในหน้าจอจะปรับเป็นราคาพิเศษของเกรดนั้นทันที พร้อมแสดงราคาเดิมและส่วนลดที่ได้รับ
   - เมื่อกดยืนยันการขาย ระบบจะบันทึกยอดขายเพิ่มเข้าไปในยอดซื้อสะสม (Accumulated Spend) ของลูกค้ารายนั้นโดยอัตโนมัติ

2. **หน้าจัดการรายชื่อลูกค้าและระดับเกรด (Customer Management Center)**:
   - สามารถเข้าถึงได้ง่ายจากปุ่มทางลัดด้านบนใน Header และปุ่มเลือกในหน้าซื้อขาย
   - แสดงสถิติภาพรวม: จำนวนลูกค้าทั้งหมด, ลูกค้าแต่ละเกรด, และยอดซื้อสะสมรวม
   - แถบกรองตามเกรด (ทั้งหมด, เกรด A, เกรด B, เกรด C, เกรด D, ลูกค้าทั่วไป)
   - แถบค้นหาแบบพิมพ์หาทันที (Real-time Search) ตามชื่อ, เบอร์โทรศัพท์, หรือทะเบียนรถ
   - การ์ดลูกค้าแต่ละรายแสดง: ชื่อ, เบอร์โทร, เกรด, ยอดซื้อสะสม, จำนวนบิล, ป้ายรุ่นรถ/ทะเบียน และปุ่มโทรออก/แก้ไข/ลบ

3. **การตั้งค่าราคาพิเศษในหน้าสินค้า (Custom Price per Grade in Product Form)**:
   - ในหน้าต่างเพิ่ม/แก้ไขสินค้า (`AddEditProductModal`) มีกล่องพับเก็บได้ "กำหนดราคาเฉพาะตามเกรดลูกค้า (ทางเลือก)"
   - สามารถกรอกราคาเจาะจงสำหรับเกรด A, B, C, D (เช่น ราคาขายปกติ 150 บาท, เกรด A: 120 บาท, เกรด B: 130 บาท)

### อัตลักษณ์และธีมภาพ (Visual Identity & Theme)

- **จานสี (Color Palette - 60-30-10 Rule)**:
  - **พื้นหลังหลัก (60%)**: Dark Neutral `#252C33` และ `#20262D`
  - **พื้นผิวการ์ดและโครงสร้าง (30%)**: Surface Slate `#3A4750` พร้อมเส้นขอบแบบ Hairline `#475662`
  - **สีเน้นการกระทำ (10%)**: Golden Yellow `#F6C90E` สำหรับปุ่มหลักและไฮไลต์สำคัญ
  - **สีประจำเกรดลูกค้า (Grade Accents)**:
    - **เกรด A (ช่าง VIP/อู่คู่ค้า)**: สีทองพรีเมียม Amber/Gold (`bg-amber-400/20 text-amber-300 border-amber-400/40`)
    - **เกรด B (ลูกค้าส่ง/ซื้อประจำ)**: สีฟ้าสดใส Sky Blue (`bg-sky-500/20 text-sky-300 border-sky-400/40`)
    - **เกรด C (สมาชิกทั่วไป)**: สีเขียวมรกต Emerald (`bg-emerald-500/20 text-emerald-300 border-emerald-500/40`)
    - **เกรด D (ลูกค้าส่วนลดพิเศษ)**: สีม่วงคราม Indigo (`bg-indigo-500/20 text-indigo-300 border-indigo-500/40`)
    - **ลูกค้าทั่วไป**: สีเทากลาง Slate (`bg-slate-700/50 text-slate-300 border-slate-600`)
- **การจัดวางและตัวพิมพ์ (Typography)**: ฟอนต์ภาษาไทย `Prompt` ร่วมกับตัวเลขแบบโมโนสเปซ (`font-mono tabular-nums`) สำหรับราคา เปอร์เซ็นต์ และเบอร์โทรศัพท์

## 3. การตัดสินใจเชิงผลิตภัณฑ์และสถาปัตยกรรม (Key Product Decisions)

- **การคิดราคาแบบผสมผสาน (Hybrid Pricing Hierarchy)**:
  $$\text{Effective Price} = \begin{cases} 
  \text{customGradePrice}(P, G) & \text{ถ้ามีการกำหนดราคาเฉพาะของสินค้านั้นไว้} \\
  \left\lceil \text{sellingPrice}(P) \times \left(1 - \frac{\text{tierDiscount}(G)}{100}\right) \right\rceil & \text{ถ้าไม่มีราคาเฉพาะ (คิดส่วนลดตามเกรด ปัดเศษขึ้นเต็มบาท)} \\
  \text{sellingPrice}(P) & \text{ลูกค้าทั่วไปหรือไม่มีส่วนลด}
  \end{cases}$$
- **การจัดเก็บข้อมูลแบบ Local-First พร้อมคลาวด์ Firestore**:
  - รองรับการทำงานทั้งแบบออฟไลน์/Sandbox (localStorage) และบันทึกลง Firestore (`customers`, `customer_tiers`)
  - อัปเดตยอดซื้อสะสมทันทีหลังจบการขายในหน้า POS โดยไม่ทำให้ระบบหน่วง

### โครงสร้างข้อมูลใหม่ (Data Structures)

```typescript
// 1. ระดับเกรดลูกค้าและการตั้งค่าส่วนลด
export type CustomerGrade = 'A' | 'B' | 'C' | 'D' | 'general';

export interface CustomerTier {
  grade: CustomerGrade;
  name: string;           // เช่น "เกรด A (ช่างประจำ/อู่คู่ค้า)"
  discountPercent: number;// เปอร์เซ็นต์ส่วนลด เช่น 15
  description?: string;
  badgeColor: string;
}

// 2. ข้อมูลลูกค้า/สมาชิก
export interface CustomerItem {
  id: string;
  name: string;
  phone: string;
  grade: CustomerGrade;
  vehiclePlate?: string;  // ทะเบียนรถ เช่น "กข 1234 หนองคาย"
  vehicleModel?: string;  // รุ่นรถ เช่น "Wave 110i", "PCX 160"
  notes?: string;         // บันทึกเพิ่มเติม เช่น "อู่ช่างเล็ก ท่าบ่อ"
  totalSpend: number;     // ยอดซื้อสะสมรวม (บาท)
  purchaseCount: number;  // จำนวนครั้งที่ซื้อ
  createdAt: string;
  updatedAt: string;
}

// 3. ขยายโครงสร้างสินค้าเพื่อรองรับราคาเฉพาะเกรด (Optional)
// ใน ProductItem:
// gradePrices?: {
//   A?: number;
//   B?: number;
//   C?: number;
//   D?: number;
// };
```

## 5. แผนการดำเนินงานและขั้นตอนแก้ไขโค้ด (Step-by-Step Implementation Steps)

1. **อัปเดต Data Model (`src/types.ts`)**:
   - เพิ่ม `CustomerGrade`, `CustomerTier`, `CustomerItem`
   - เพิ่มฟิลด์ `gradePrices?: Partial<Record<CustomerGrade, number>>` ใน `ProductItem`
   - เพิ่มฟิลด์ `customerId?: string`, `customerGrade?: CustomerGrade`, `discountAmount?: number` ใน `Transaction`
2. **สร้าง Tier Pricing Helper Utilities (`src/utils/pricingUtils.ts`)**:
   - ฟังก์ชันคำนวณราคาขายตามเกรด (`calculatePriceForCustomer(product, grade, tiers)`)
   - ฟังก์ชันจัดรูปแบบส่วนลดและป้ายเกรด
3. **สร้างคอมโพเนนต์จัดการลูกค้า (`src/components/CustomerManagementModal.tsx`)**:
   - หน้าค้นหาและแสดงรายชื่อลูกค้า พร้อมป้ายเกรด ยอดสะสม และประวัติ
   - หน้าฟอร์มเพิ่ม/แก้ไขข้อมูลลูกค้า (ชื่อ, เบอร์โทร, เกรด, ทะเบียนรถ, หมายเหตุ)
   - แท็บตั้งค่าเปอร์เซ็นต์ส่วนลดของแต่ละเกรด (A, B, C, D)
4. **สร้างคอมโพเนนต์เลือกลูกค้าแบบเร่งด่วน (`src/components/CustomerPickerModal.tsx`)**:
   - สำหรับกดเลือกในหน้าขาย (Staff POS และ BuySellTab) พิมพ์ค้นหาด้วยชื่อ/เบอร์โทร หรือกด "+ เพิ่มลูกค้าใหม่" ได้ทันที
5. **ปรับปรุงโหมดพนักงาน (`src/components/StaffPosView.tsx`)**:
   - แสดงแถบลูกค้าที่เลือกพร้อม Badge เกรดและ % ส่วนลด
   - คำนวณราคาต่อหน่วยในตะกร้าและหน้าการ์ดสินค้าตามเกรดลูกค้าที่เลือก
   - ปรับการพิมพ์ใบเสร็จ (ReceiptModal) ให้แสดงส่วนลดและเกรดลูกค้าชัดเจน
   - เมื่อกดชำระเงิน เพิ่มยอดซื้อสะสมให้ลูกค้าอัตโนมัติ
6. **ปรับปรุงหน้าซื้อ/ขายหลัก (`src/components/BuySellTab.tsx`)**:
   - เชื่อมต่อตัวเลือกลูกค้าและคำนวณราคาตามเกรดในลักษณะเดียวกัน
7. **ปรับปรุงฟอร์มสินค้า (`src/components/AddEditProductModal.tsx`)**:
   - เพิ่มส่วนกรอกราคาเฉพาะเกรด A, B, C, D (ตัวเลือกเสริม)
8. **อัปเดตการซิงค์ข้อมูลกับ Firestore และ Blueprint (`src/firebase.ts`, `firebase-blueprint.json`)**:
   - เพิ่มคอลเลกชัน `customers` และ `customer_tiers`
   - ทดสอบและคอมไพล์ระบบเพื่อความสมบูรณ์แบบ
